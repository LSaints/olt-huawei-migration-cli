# 🚀 olt-huawei-migration-cli

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter o **Python 3.8+** instalado em sua máquina:
* [Baixar Python para Windows/Mac/Linux](https://www.python.org/downloads/)
* **Atenção (Windows):** Ao instalar, marque a caixa **"Add Python to PATH"**.

---

## ⚡ Instalação Rápida (Recomendado)

Criamos scripts que configuram o ambiente, instalam as dependências e iniciam o programa para você automaticamente.

### **Windows**
1. Localize o arquivo `run.bat` na pasta do projeto.
2. Dê um **duplo clique** no arquivo.
3. O script fará tudo sozinho e abrirá a aplicação.

### **Linux / macOS**
1. Abra o terminal na pasta do projeto.
2. Dê permissão de execução:
   ```bash
   chmod +x run.sh
   ```
3. Execute o script
    ```bash
    ./run.sh
    ```
